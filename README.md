### Featured Project

**[DAMMIT.pro](https://dammit.pro)** — a production web application for managing Solana DeFi liquidity positions on Meteora's Dynamic AMM V2 pools, live for over a year. Built with Next.js 15 and React 19, it handles real-time position tracking, fee claiming and rebalancing, pool discovery across hundreds of live pools via WebSocket/RPC, and token swaps routed through the Jupiter API with MEV protection. Integrates directly with the Solana blockchain (web3.js, SPL Token, 19+ wallet adapters) and the Meteora CP-AMM SDK.

*(You'll need a Solana wallet like Phantom to actually use it — it's a DeFi tool, not a public demo.)*
